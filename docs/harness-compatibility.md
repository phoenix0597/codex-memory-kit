## Общий контракт

Пять профилей используют одинаковые канонические файлы. Различается штатное место короткого адаптера. Все адаптеры читают `.agents/memory-kit.conf` относительно текущего home, получают `GLOBAL_MEMORY_DIR`, затем непосредственно читают общие Markdown-файлы. Отдельный сервер, нативный memory tool или автоматический Markdown-import не требуется.

Локатор содержит UTF-8 строки `VERSION=1`, `GLOBAL_MEMORY_DIR=<absolute path>`, `KIT_ROOT=<absolute path>`. Значение начинается после первого `=`; это данные без shell-исполнения. Пути конкретной машины остаются здесь. Текст переносимой общей и проектной памяти не зависит от того, где клонирован kit.

| Профиль | Штатный глобальный файл | Что передать для нестандартного корня | Проект |
|---|---|---|---|
| `codex` | `<CODEX_HOME>/AGENTS.md` | `CodexDir` / `--codex-dir` | `AGENTS.md`, с учётом overrides |
| `dsh` | `<DSH_HOME>/AGENTS.md` | `DshDir` / `--dsh-dir` | `AGENTS.md` и штатная цепочка плагина |
| `mimocode` | `<MiMoCode config>/AGENTS.md` | `MimocodeConfigDir` / `--mimocode-config-dir` | `AGENTS.md` при включённой загрузке |
| `zcode` | `<ZCode root>/AGENTS.md` | `ZcodeDir` / `--zcode-dir` | `AGENTS.md`, зависит от `priorityFiles` |
| `antigravity` | `<Antigravity root>/GEMINI.md` | `AntigravityDir` / `--antigravity-dir` | Общий `AGENTS.md` и `.agents/rules/antigravity-memory-adapter.md` |

PowerShell-параметры в таблице имеют префикс `-`. `all` выбирает все пять профилей, `none` оставляет общий слой без штатных адаптеров. Выбор каталога в kit должен совпадать с настройками самого харнесса; kit не меняет их автоматически.

Без явного `Home` команды учитывают `CODEX_HOME`, `DSH_HOME`, `MIMOCODE_CONFIG_DIR`, `MIMOCODE_HOME` и `XDG_CONFIG_HOME`. При явном `Home` корни строятся относительно выбранного пользователя; нужные исключения передавайте отдельными параметрами. `KIT_ROOT` берётся из выполняемого набора, а `SourceRoot` меняет только источник шаблонов.

## Codex

Codex читает глобальные инструкции из `CODEX_HOME` (по умолчанию `~/.codex`): первый непустой `AGENTS.override.md`, иначе `AGENTS.md`. Проектная цепочка идёт от корня проекта до текущего каталога, с одним выбранным файлом на уровень. Размер объединяемых инструкций ограничивает `project_doc_max_bytes`, по умолчанию 32 KiB. Короткий адаптер оставляет контекст для проекта. `~/AGENTS.md` не заменяет файл профиля. [Официальная документация AGENTS.md](https://learn.chatgpt.com/docs/agent-configuration/agents-md)

Обязательная диагностика: непустой глобальный override, вложенные overrides, фактический `CODEX_HOME`, текущая рабочая директория и доступ к локатору/общим файлам. Настройки sandbox и ACL относятся к конкретной среде исполнения; общий рецепт изменения прав в архитектуру kit не входит.

## DSH / DeepSeek Harness

Стандартный плагин `dsh-agent-instructions` читает `$DSH_HOME/AGENTS.md`, затем `$DSH_AGENTS_HOME/AGENTS.md`; обычные каталоги — `~/.dsh` и `~/.agents`. Следом идут проектные инструкции. Поэтому `~/AGENTS.md` недостаточен для глобального подключения. Произвольный профиль может менять или отключать плагин; наличие `.dsh/AGENTS.md` само по себе не доказывает его работу. [Исходная документация плагина](https://github.com/deepseek-ai/deepseek-harness/blob/master/packages/context/agent-instructions/README.md)

Адаптер kit использует первый штатный файл DSH. Уже существующие инструкции в общем `.agents/AGENTS.md` продолжают действовать и могут конфликтовать с ним: проверяйте их содержимое. Встроенные сессии, compaction и todo не являются отдельным источником канонических правил kit.

Загрузчик выбирает первый существующий глобальный файл: явный `MIMOCODE_CONFIG_DIR/AGENTS.md`, затем конфигурационный `AGENTS.md`, затем совместимый `~/.claude/CLAUDE.md`, если совместимость разрешена. Это не объединение всех глобальных файлов. [Загрузчик инструкций](https://github.com/XiaomiMiMo/MiMo-Code/blob/4e58a80184794d52d913d4b886b96f496f2c7020/packages/cli/src/session/instruction.ts)

Конфигурационный корень определяется `MIMOCODE_HOME/config` либо XDG-каталогом `mimocode`; обычный fallback — `~/.config/mimocode`. Путь установки Desktop-приложения не является путём конфигурации. Для отличающейся установки передайте её фактический каталог через `MimocodeConfigDir`. [Определение глобальных путей](https://github.com/XiaomiMiMo/MiMo-Code/blob/4e58a80184794d52d913d4b886b96f496f2c7020/packages/shared/src/global.ts)

Проектная загрузка может быть отключена через `MIMOCODE_DISABLE_PROJECT_CONFIG`; короткий проектный `AGENTS.md` может дополняться `CLAUDE.md`. Проверяйте фактический набор инструкций. Нативный BM25 memory tool индексирует собственную область данных, а не произвольные файлы kit автоматически. Memory/history — вспомогательные возможности. [Memory tool](https://github.com/XiaomiMiMo/MiMo-Code/blob/4e58a80184794d52d913d4b886b96f496f2c7020/packages/cli/src/tool/memory.txt), [History tool](https://github.com/XiaomiMiMo/MiMo-Code/blob/4e58a80184794d52d913d4b886b96f496f2c7020/packages/cli/src/tool/history.txt)

Локально обнаружены MiMo Desktop `26.924.240030` и npm `@mimo-ai/cli` `0.1.3`. Это сведения об установленных файлах; они не доказывают совпадение бинарника с указанным upstream commit.

## ZCode

Речь о ZCode от `zai-org`, не об одноимённых продуктах. Документированы глобальный `~/.zcode/AGENTS.md` и рабочий `AGENTS.md`; Markdown include/import не поддерживается. [Официальная инструкция](https://zcode.network/en/docs/agents/#project-instructions-file)

Проверен upstream commit `3c5b227649371507ddc4eb46ac5133afe6db1cab`. Загрузчик читает глобальный файл из `.zcode/AGENTS.md` в home, выбираемом из `HOME`, `USERPROFILE`, затем системного home; переменная внутреннего каталога данных не меняет этот путь. Рабочий файл ищется от текущей директории вверх до корня Git; выбирается ближайший, без объединения всех родительских `AGENTS.md`. По умолчанию лимит составляет 100 KiB. Пользовательский `priorityFiles` без `AGENTS.md` может отключить и глобальную загрузку. [Загрузчик инструкций](https://github.com/zai-org/ZCode/blob/3c5b227649371507ddc4eb46ac5133afe6db1cab/apps/zcode-cli/packages/adapters/src/context/index.ts)

Для стандартного ZCode поддерживается именно `~/.zcode`: произвольный `ZcodeDir` в kit полезен для подготовки файлов, но сам по себе не перенастраивает загрузчик. При переопределённом процессе `HOME` передайте совпадающий `Home` командам kit; автоматическая `$HOME` PowerShell и переменная среды `HOME` могут различаться. Тогда глобальный адаптер и локатор будут подготовлены внутри одного фактического home. [Дизайн загрузки](https://github.com/zai-org/ZCode/blob/3c5b227649371507ddc4eb46ac5133afe6db1cab/apps/zcode-cli/docs/design/agents-user-instructions-merge.md)

`ReadSessionContext` существует, но доступность стратегий и fallback определяется версией. Compaction не гарантирует полноту результата. Прямое чтение SQLite, session index или snapshots не является поддерживаемым интерфейсом kit. [Контракт инструмента](https://github.com/zai-org/ZCode/blob/3c5b227649371507ddc4eb46ac5133afe6db1cab/apps/zcode-cli/packages/contracts/src/tools/read-session-context.ts)

Нативная Project Memory — отдельная опция с дополнительным контекстом. Kit не включает её. При проверке загрузки нужны наблюдаемые источники или несекретный контрольный маркер, а не одно заявление модели «я прочитал». [Официальный протокол проверки памяти](https://github.com/zai-org/ZCode/blob/3c5b227649371507ddc4eb46ac5133afe6db1cab/apps/zcode-cli/docs/usage/11-memory.md)

Локально обнаружен ZCode `3.16.2.8769`, пакет Desktop — `3.16.2`. Это не утверждение о точном соответствии текущему upstream.

## Antigravity

Общие документированные точки входа App/CLI/IDE — `~/.gemini/GEMINI.md` или `AGENTS.md`, а проектные — `AGENTS.md`, `GEMINI.md`, `.agents/rules/*.md`. Для файлов внутри `rules/` обязателен корректный YAML `trigger`. Kit использует `always_on` и краткий `description`; прежний путь `.gemini/rules/` не является документированным проектным механизмом. [Rules](https://www.antigravity.google/docs/rules/)

Лимит rule — **24 000 UTF-8 байт после inline includes**; суммарный бюджет активных rules — **20 000 токенов**. Большие правила могут заменяться указателями. Поэтому внешняя общая память читается обычными файловыми средствами, без `@[label](path)` для встраивания её содержимого. [Ограничения rules](https://www.antigravity.google/docs/rules/#size-limits-and-token-budgets)

`transcript.jsonl`, `grep_search` и выдаваемые средой пути `transcriptPath` / `artifactDirectoryPath` подтверждены документацией hooks. Корни данных различаются между App, CLI и IDE; их не следует зашивать в переносимую память. Артефакты сохраняются, но не заменяют проектный источник решений. [Hooks](https://www.antigravity.google/docs/hooks/), [Artifacts](https://antigravity.google/docs/artifacts)

`/learn` предлагает изменения rules/skills через `learning_proposal.md` и review. Он не нужен для установки. Skills загружаются по необходимости и не заменяют обязательный bootstrap памяти. [Learn](https://www.antigravity.google/docs/commands/learn/), [Skills](https://www.antigravity.google/docs/skills?tab=ide)

Локальные версии: App `2.23.1.0`, IDE `2.0.3` (commit `4e2e10a9285aefbdcb898ae5e50dde45e9c7f505`, сборка 22.05.2026), CLI `1.3.5`. Версии получены из метаданных файлов и `agy --version`. Текущая официальная документация описывает развивающийся продукт; фактическую активацию старой версии нужно проверять отдельно.

## Проверка в реальной сессии

Автоматические интеграционные тесты подтверждают генерацию файлов, форматы, ссылки, сохранность пользовательского текста и перенос. Для конкретной установленной среды дополнительно проверьте загрузку:

1. Запустите `check` с выбранным агентом и `Strict`, затем начните новую сессию в нужном проекте.
2. В штатном просмотре инструкций, журналах или наблюдаемых запросах найдите реально активный глобальный файл и проектный `AGENTS.md`; проверьте overrides и настройки профиля.
3. Попросите назвать путь локатора, выбранной общей памяти, текущую задачу и относящееся к ней правило. Сверьте с файлами и доступными следами чтения. Самоотчёт модели служит подсказкой, но не отдельным доказательством.
4. При необходимости используйте несекретный временный контрольный маркер в отдельной тестовой установке. Удалите его после проверки; не добавляйте секреты или скрытые команды.
5. При недоступном чтении или конфликте исправьте конкретный путь/профиль и повторите проверку новой сессией. Не включайте `Force` на всю память как универсальное исправление.

Адаптеры не обходят sandbox и не включают отключённые плагины. В read-only среде агент может пользоваться памятью без возможности её обновить; это нужно явно отметить в результате.
